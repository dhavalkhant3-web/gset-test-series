# GSET Test Series v1.4

Complete Flutter source package for the GSET Paper-I bilingual test series.

## Build APK (Windows)
1. Install Flutter SDK and Android Studio with an Android SDK.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter build apk --release`.
5. APK will be created at `build\app\outputs\flutter-apk\app-release.apk`.

The app source/data are already included. Do not move the `assets` or `lib` folders.
