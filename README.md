# GSET Test Series v1.5

Flutter source package for the GSET Paper-I test series and 36-subject Paper-II hub.

Hindi is connected with 800 Paper-II questions across 14 sessions. Its 300 Paper-III questions are preserved as a separate archive. Hindi source review and syllabus mappings remain in progress.

## Build APK (Windows)
1. Install Flutter SDK and Android Studio with an Android SDK.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter build apk --release`.
5. APK will be created at `build\\app\\outputs\\flutter-apk\\app-release.apk`.

The app source/data are already included. Do not move the `assets` or `lib` folders.
